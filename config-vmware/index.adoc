= Démarrage rapide pour la configuration de l'hôte VMware dans le système de stockage E-Series
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La méthode VMware Express d'installation de votre baie de stockage et d'accès à SANtricity System Manager est idéale pour configurer un hôte VMware autonome avec un système de stockage E-Series. Elle est conçue pour rendre le système de stockage opérationnel le plus rapidement possible, en minimisant les étapes de décision.



[[procedure-overview]]
== Présentation de la procédure

La méthode express comprend les étapes suivantes, également décrites dans le link:understand-vmware-workflow-concept.html["Workflow VMware"].

. Configurez l'un des environnements de communication suivants :
+
** link:nvme-fc-perform-specific-task.html["NVMe over Fibre Channel"]
** link:fc-perform-specific-task.html["Fibre Channel (FCP)"]
** link:iscsi-perform-specific-task.html["ISCSI"]
** link:sas-perform-specific-task.html["SAS"]
** link:nvme-roce-perform-specific-task.html["NVMe over RoCE"]
** link:nvme-tcp-perform-specific-task.html["NVMe sur TCP"]


. Création de volumes logiques sur la baie de stockage.
. Rendre les volumes disponibles pour l'hôte de données.
